# 📷 לידים לצלמים – אוטומציה יומית

מערכת שרצה **כל יום אוטומטית**, מחפשת ברשתות החברתיות אנשים שכותבים
"מחפשת צלם", "ממליצים על צלם", "צריך צלם לבר מצווה" וכו',
**מסננת החוצה חיפושי עבודה / משרות / צלמים שמפרסמים את עצמם**,
ושולחת לכם את הלידים החדשים לטלגרם ו/או למייל (+ קובץ CSV לאקסל).

```
Google (site:facebook.com / instagram.com / tiktok ...)  ┐
קבוצות פייסבוק ציבוריות (Apify)                           │      ┌─ סינון: כוונה + "צלם"
האשטגים באינסטגרם (Apify)                                ├──►   ├─ פסילת משרות/גיוס/"צלם מחפש עבודה"
Reddit                                                    │      ├─ פסילת פרסומות של צלמים
Google Alerts / rss.app (RSS)                             ┘      └─ הסרת כפילויות ──► טלגרם / מייל / CSV
```

## מה נחשב ליד?

| ✅ ליד | ❌ לא ליד |
|---|---|
| מחפשת צלמת לחתונה באוגוסט, ממליצות? | צלם מחפש עבודה באזור המרכז |
| מישהו מכיר צלם טוב לצילומי משפחה? | דרושים צלמים לחברת הפקות, משרה מלאה |
| צריכה צלמת ניו בורן דחוף | דרוש צלם למשרה חלקית, לשלוח קו"ח |
| Looking for a photographer for our engagement | [For Hire] wedding photographer |
| דרוש צלם לאירוע יום הולדת 50 | נשארו תאריכים פנויים! מבצע חבילות צילום |

כל ליד מקבל **ציון** (כוונה ברורה, סוג אירוע, שאלה) ו**סוג אירוע** (חתונה, בר מצווה,
ברית, הריון/ניו בורן, משפחה, תדמית, מוצר, נדל"ן...). הלידים הטובים מופיעים ראשונים.

## הפעלה – 10 דקות

### 1. מקור חיפוש (חובה – לפחות אחד)
* **Serper (מומלץ)** – נרשמים ב-[serper.dev](https://serper.dev), מקבלים 2,500 חיפושים חינם,
  אחר כך ~1$ לכל 1,000. בהגדרות ברירת המחדל זה ~30 חיפושים ביום (≈1$ לחודש).
* **Google Programmable Search** – חלופה עם 100 חיפושים חינם ביום:
  יוצרים מנוע ב-[programmablesearchengine.google.com](https://programmablesearchengine.google.com)
  ומפתח API ב-Google Cloud (Custom Search API).

### 2. ערוץ קבלת לידים (חובה – לפחות אחד)
* **טלגרם (מומלץ)** – פותחים בוט אצל `@BotFather` ומקבלים `TELEGRAM_BOT_TOKEN`.
  שולחים לבוט הודעה, ואז נכנסים ל-`https://api.telegram.org/bot<TOKEN>/getUpdates`
  ולוקחים את `chat.id` → זה `TELEGRAM_CHAT_ID`.
* **מייל** – ב-Gmail יוצרים "סיסמת אפליקציה" (App Password) ומגדירים
  `SMTP_HOST=smtp.gmail.com`, `SMTP_USER`, `SMTP_PASSWORD`, `EMAIL_TO`.

### 3. להכניס את המפתחות ל-GitHub
`Settings → Secrets and variables → Actions → New repository secret`
ולהוסיף את השמות מהקובץ [`.env.example`](.env.example).

### 4. זהו 🎉
ה-Workflow [`daily-leads.yml`](.github/workflows/daily-leads.yml) רץ **כל יום ב-07:00/08:00** (שעון ישראל).
להרצה מיידית: `Actions → Daily photographer leads → Run workflow`.
ה-CSV נשמר גם כ-Artifact בכל הרצה.

## פייסבוק ואינסטגרם – איך זה עובד

לפייסבוק ולאינסטגרם **אין API רשמי** שמאפשר לחפש פוסטים של אנשים אחרים, ולכן משתמשים בשתי דרכים חוקיות:

1. **Google `site:`** – פוסטים ציבוריים שגוגל אינדקס ביממה האחרונה
   (`site:facebook.com ("מחפשת צלם" OR "ממליצים על צלם" ...)`). עובד מיד, בלי הגדרות נוספות.
2. **Apify** – סריקה ישירה של **קבוצות פייסבוק ציבוריות** ו**האשטגים באינסטגרם**.
   זה המקור הכי חזק – רוב הבקשות לצלם נכתבות בקבוצות כמו קבוצות כלות, אמהות,
   קבוצות עיר/שכונה, ועסקים קטנים.
   * נרשמים ב-[apify.com](https://apify.com) (יש קרדיט חינמי חודשי), מעתיקים את ה-API token ל-`APIFY_TOKEN`.
   * ב-`config.yaml` תחת `apify_facebook_groups.groups` מוסיפים קישורים לקבוצות ציבוריות.
   * ב-`apify_instagram_hashtags.hashtags` עורכים את רשימת ההאשטגים.

## עוד אופציות (כבר בנויות במערכת)

| מקור | איך מפעילים | הערות |
|---|---|---|
| **TikTok, Threads, X** | אוטומטי דרך Serper/Google | ברשימה `search_sites` |
| **Reddit** | אוטומטי, בלי מפתח | בעיקר באנגלית (תיירים, זוגות מחו"ל שמתחתנים בארץ) |
| **Google Alerts** (חינם!) | ב-[google.com/alerts](https://www.google.com/alerts) יוצרים התראה על `"מחפשת צלם"`, בוחרים *Deliver to: RSS feed*, ומדביקים את הקישור ב-`rss.feeds` | מכסה גם פורומים, אתרי שאלות ותשובות, בלוגים |
| **rss.app / FetchRSS** | יוצרים פיד RSS מקבוצת פייסבוק / עמוד אינסטגרם ומדביקים ב-`rss.feeds` | חלופה ל-Apify |
| **אתרים נוספים** | מוסיפים דומיין ל-`search_sites` (למשל `linkedin.com`, `tapuz.co.il`) | שימו לב – בלינקדאין יש הרבה משרות, הסינון יפסול אותן |

## התאמה אישית – `config.yaml`

* `search_phrases` – הביטויים שמחפשים (אפשר להוסיף "צלם לחתונה בצפון", עיר מסוימת וכו').
* `search_sites` – באילו רשתות לחפש.
* `classifier.job_exclusions` / `promo_exclusions` – מילים שפוסלות פוסט.
* `classifier.event_types` – סוגי אירועים שמעלים את הציון.
* `search_time_window` – `d` = יממה אחרונה, `w` = שבוע.

## הרצה מקומית

```bash
pip install -r requirements.txt
cp .env.example .env   # למלא מפתחות
set -a; source .env; set +a
python -m leadbot --dry-run   # מציג לידים בלי לשלוח ובלי לסמן כ"נראו"
python -m leadbot             # הרצה אמיתית
python -m pytest -q           # בדיקות של הסינון
```

הרצה יומית על מחשב/שרת במקום GitHub: `crontab -e` →
`0 7 * * * cd /path/to/repo && set -a && . ./.env && python3 -m leadbot`
